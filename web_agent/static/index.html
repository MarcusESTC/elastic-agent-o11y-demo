The app calls Gemini directly. Its question, answer and tool activity are recorded as telemetry. Masking happens later, inside Elasticsearch during ingestion.

Redaction is part of ingestion.

Dedicated trace and log streams require Elastic’s final redact pipeline. The app makes no separate redaction request and writes no extra chat-log copy. Use “View Elastic copy” after a run to inspect the stored result.
